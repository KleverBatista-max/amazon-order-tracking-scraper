# Amazon order tracking scraper

Selenium notebook that opens your Amazon order history in your own Chrome profile, clicks every **Track package** button and collects the tracking IDs, so you don't have to copy them by hand. `hotkeys.ahk` has the AutoHotkey shortcuts that went with it.

- Update the Chrome profile and chromedriver paths (`C:\Users\YOU\...`) for your machine.
- Amazon's page markup changes often; selectors may need adjusting.
- Use only on your own account and respect Amazon's terms.
